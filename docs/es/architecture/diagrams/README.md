# Diagramas de arquitectura y UML

Estas referencias visuales se originaron en el trabajo de metodología y arquitectura. Facilitan la
comprensión por parte de los agentes, pero los contratos escritos en
`docs/04_ARCHITECTURE.md` siguen siendo la referencia operativa con autoridad cuando un diagrama es
ambiguo.

Fuente de Figma:
https://www.figma.com/design/um6d9rfB1cCeCSXRI4sEIS/UXAudit---Architecture?node-id=0-1&t=EPcj08OdI7nwVeXH-1

Las figuras esperadas incluyen:

- arquitectura y canalización de procesamiento;
- flujo de validación;
- evaluación y categorías de reglas;
- caso de uso;
- actividad;
- componente;
- paquete;
- clase;
- secuencia;
- estado;
- despliegue/persistencia;
- estructura propuesta del repositorio.
