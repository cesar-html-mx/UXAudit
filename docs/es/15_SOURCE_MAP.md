# Mapa de fuentes

El harness se derivó de los siguientes materiales del proyecto proporcionados por los autores:

- Documento completo de metodología y arquitectura del TFM (aproximadamente 161 páginas
  renderizadas).
- Entrega condensada de metodología y arquitectura.
- Tema 3: Pruebas de la herramienta.
- Figuras de arquitectura y UML, incluida la fuente de Figma.

La especificación operativa es deliberadamente autónoma para que las sesiones futuras de Codex no
necesiten el chat original. Cuando el documento académico y la implementación del repositorio
diverjan, se debe registrar la diferencia y decidir si es necesario actualizar el documento o la
implementación; no se debe ocultar.
