# UXAudit post-harness dossier / Expediente post-harness de UXAudit

[Español](es/00_INDEX.md) | [English](en/00_INDEX.md)

## Español

Este expediente conserva la preparación pública, publicación, endurecimiento de seguridad y
validación de consumo realizadas después de cerrar el harness M01–M06 de UXAudit. Es evidencia
académica archivística: no redefine los hitos, no reabre el harness y no forma parte de las
instrucciones de uso del producto.

La rama prevista para conservarlo es `evidence/post-harness-v0.1.0`. No debe fusionarse con `main`.
Los documentos pueden copiarse a una entrega externa sin arrastrar el material interno al recorrido
público del proyecto. Como el repositorio es público, esta rama también será públicamente
descubrible en cuanto se envíe al remoto, aunque nunca se fusione.

El expediente no contiene valores de tokens, secrets, códigos de recuperación ni credenciales.
Sí registra hechos operativos no secretos sobre GitHub y npm. Distingue entre evidencia pública
reproducible, evidencia verificable en Git, confirmaciones del mantenedor no reproducibles mediante
API pública y observaciones temporales de la sesión.

## English

This dossier preserves the public preparation, publication, security hardening, and consumer
validation performed after the UXAudit M01–M06 harness was closed. It is archival academic evidence:
it does not redefine milestones, reopen the harness, or form part of the product usage instructions.

The intended archival branch is `evidence/post-harness-v0.1.0`. It must not be merged into `main`.
The documents can be copied into an external submission without adding internal material to the
project's public user path. Because the repository is public, this branch will also be publicly
discoverable as soon as it is pushed, even if it is never merged.

The dossier contains no token, secret, recovery-code, or credential values. It does record
non-secret operational facts about GitHub and npm. It distinguishes reproducible public evidence,
Git-verifiable evidence, maintainer confirmations not reproducible through a public API, and
temporary session observations.
