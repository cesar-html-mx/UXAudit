# UXAudit Evidence

Each milestone stores reproducible evidence here. Use the template in
`.github/harness/templates/TEST_EVIDENCE_TEMPLATE.md`.

Required structure:

```text
evidence/
├── m01-bootstrap/
├── m02-discovery/
├── m03-parsing/
├── m04-rules/
├── m05-reporting/
├── m06-validation/
├── usability/
└── security/
```

Do not commit secrets, private absolute paths, or modified raw output.
